# IT Security Policy

Harbor Lane Logistics is a made-up company. This document is sample data.

## Passwords

Passwords must be at least 14 characters long. Use the company password
manager and never reuse a work password on another site.

Multi factor authentication is required for email, VPN, and all cloud
consoles.

## Devices

Company laptops must have disk encryption turned on and must lock after
5 minutes without activity. Install updates within 7 days of release.

Report a lost or stolen device to the IT service desk within 1 hour.

## Data handling

Customer data must stay in approved company systems. Do not copy it to
personal devices, personal email, or public file sharing services.

## Reporting incidents

Report suspected phishing or any security incident to
security@harborlane.example right away. Do not try to investigate it
yourself.

## Software

Only install software from the company software catalogue. Other software
needs approval from the IT team first.
